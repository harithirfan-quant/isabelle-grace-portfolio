# Logos (optional)

The site auto-generates clean monogram placeholders from each company/school
name, so you don't need any images to launch.

If you'd like real logos:

1. Drop image files here, e.g. `bank-islam.png`, `unimap.png`.
2. Open `components/logo-badge.tsx` and swap the initials block for an
   `<Image src="/logos/your-file.png" ... />`.

Recommended: square PNGs with transparent backgrounds, ~128×128px.
